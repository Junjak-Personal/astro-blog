# Added technology logos

Preference: Simple Icons, then theSVG, then SVGL. Logos are served locally.
Monochrome assets have light (#333333) and dark (#EEEEEE) variants.
The official Hermes Agent color favicon is shared by both themes.

- Simple Icons: Kotlin, Dart, Redis, Storybook, Pinia, esbuild, SQLite, FastAPI,
  Tauri, Rust, Immer, Claude and Mapbox. CC0-1.0.
  https://simpleicons.org/ · https://github.com/simple-icons/simple-icons
  Downloaded from `https://cdn.simpleicons.org/{slug}/{hex}`.
- theSVG: AWS mono, Codex and OpenAI (ChatGPT); official theme variants where available.
  https://thesvg.org/icons/aws/mono.svg
  https://thesvg.org/icons/codex/light.svg · https://thesvg.org/icons/codex/dark.svg
  https://thesvg.org/icons/openai/light.svg · https://thesvg.org/icons/openai/dark.svg
  AWS mono fill is adapted to each theme.
- Devicon: Zustand (`zustand-plain.svg`), monochrome fill adapted to each theme.
  https://github.com/devicons/devicon/tree/master/icons/zustand
- Hermes: official NousResearch Hermes Agent favicon, shared color SVG.
  https://github.com/NousResearch/hermes-agent/blob/main/website/static/img/favicon.svg

Brand names and logos remain the property of their owners.
