## Description
A Nuxt 3 Tetris game created in a single click using the code-generation feature of Perplexity AI.  
Styled with Nuxt UI 4 and Tailwind CSS, it is a client-side game deployed through SSG.  
The entire project was completed using only AI-generated code. It reminded me how easily AI can build something like Tetris, for which so much accumulated data is available.

## Tech stack
- Nuxt 3: SSG framework
- Nuxt UI 4: UI components
- Tailwind CSS: Styling
- Netlify: Static site deployment

## Main features
- Block movement, rotation, soft drop, and hard drop
- Block hold (Hold) and next-block preview (Next)
- Score, line, and level systems
- Pause function
- Dark theme UI
