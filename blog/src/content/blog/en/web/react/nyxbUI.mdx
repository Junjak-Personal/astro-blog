## Introduction  
  
While searching for a good CSS Framework for this blog, I happened to find this library in [awesome shadcn-ui](!https://github.com/bytefer/awesome-shadcn-ui).  
  
Its name is Nyxb UI.  
  
For a blog, I wanted plenty of animation, and this library was exactly what I was looking for.  
  
It also felt good to use, so I wanted to write about it in a little more detail.  
  
  
  
## Nyxb UI?  
  
It can be described as a collection of ui components built on shadcn-ui.  
  
Even its website layout is quite similar to shadcn-ui's.  
  
The philosophy in its introduction says this isn't a component library. Here is the full passage:  
  
> This is **NOT** a component library. It's a collection of re-usable components that you can copy and paste into your apps.  
>  
> **What do you mean by not a component library?**  
>  
> I mean you do not install it as a dependency. It is not available or distributed via npm.  
>  
> Pick the components you need. Copy and paste the code into your project and customize to your needs. The code is yours.  
>  
> *Use this as a reference to build your own component libraries.*  
  
It says to copy and paste the pieces you need. That is not very different from what shadcn-ui says...  
  
The difference is that it includes all the shadcn-ui components along with quite a few additional components featuring animation and dynamic behavior.

## Usage  
  
Usage is also much the same as shadcn-ui.  
  
```shell title="terminal"  
pnpm dlx nyxb@latest add button  
```  
  
```tsx title="ButtonDemo.tsx"  
import { Button } from "~/components/ui/button"  
  
export function ButtonDemo() {  
   return <Button>Button</Button>  
}  
```  
  
Run the component you need through a package runner such as pnpm dlx or npx, and a file such as button.tsx will be generated in `./src/components/ui`.  
  
Customize it freely if needed, or use it as it is.  
  
Some components install dependencies because shadcn-ui relies on radix-ui. (Does that not contradict the philosophy...?)  
  
```json title="packge.json"  
{  
  "dependencies": {  
    "@radix-ui/react-avatar": "^1.1.3",
```  

## Conclusion  
  
I recommend this library if you want to add animations and dynamic elements to a website.  
  
Compared with libraries such as ant-design, its form components are a little lacking, so it may be better suited to static sites such as blogs and landing pages.  
  
I am actually using it to build this blog, and it feels quite good.  
  
I have also learned how to use Framer Motion for text animations...  
  
However, some components had serious performance problems, perhaps because of optimization issues.  
  
It seems best to choose carefully which ones to use.
